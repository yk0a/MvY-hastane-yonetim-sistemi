# Hospital Management System

A Windows Forms desktop application for managing hospital-related operations, developed with C# and SQL Server.

## Features

- Patient registration and login
- Doctor login and profile management
- Secretary login
- Doctor and department management
- Appointment management
- Patient and doctor information screens
- Announcements

## Technologies

- C#
- Windows Forms
- .NET Framework 4.7.2
- Microsoft SQL Server
- ADO.NET

## Requirements

- Visual Studio with .NET desktop development support
- .NET Framework 4.7.2 targeting pack
- SQL Server Express or a compatible SQL Server instance

## Getting Started

1. Clone or download this repository.
2. Open `HastaneProje.sln` in Visual Studio.
3. Create or configure the required SQL Server database.
4. Update the database connection settings to match your SQL Server instance.
5. Build and run the application from Visual Studio.

## Database Setup

The original local database and generated installer files are not included in this repository.

A compatible database schema and sample data must be prepared separately before the application can run. Use synthetic demonstration data only; do not use real patient information in a public repository.

## Notes

This project was developed for educational purposes. Review authentication, password storage and database access before using it in a production environment.
